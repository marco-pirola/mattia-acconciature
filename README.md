# Mattia Acconciature AH

Website for a hair salon in Bergamo, Italy. Built as a client project.

## Live site
https://mattia-acconciature.pages.dev/

## Built with
- HTML
- CSS
- JavaScript (vanilla, no frameworks)

## Features
- Services list with real prices and durations
- About section with the salon's story
- Photo and video gallery of real work
- Opening hours table
- FAQ section
- WhatsApp booking button (no contact form)
- Mobile menu and responsive layout
- Scroll reveal animations

## Notes
Built for a real client, Mattia Carrara, hairdresser in Bergamo.
Content (services, prices, photos, story) provided directly by the client.
